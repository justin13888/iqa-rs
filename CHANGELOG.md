- mark SSIM stable and document its independent-reference test

- add cargo-mutants mutation-testing setup

## [0.1.0](https://github.com/justin13888/iqa-rs/releases/tag/v0.1.0) - 2026-05-22

Initial release.

### Added

- `Image<F>` — a single image type parameterized by a compile-time
  `PixelFormat` marker that fixes color space, channel layout, and bit depth, so
  comparing mismatched images is a compile error rather than a silent wrong
  score. Supports sRGB, grayscale, and RGBA at 8- and 16-bit depth.
- `psnr` — peak signal-to-noise ratio, a native Rust implementation with
  RGB-averaged and Rec.709 luma modes.
- `ssimulacra2` — SSIMULACRA2, bound via FFI to the vendored
  [cloudinary/ssimulacra2](https://github.com/cloudinary/ssimulacra2) C++
  reference.
- Per-metric Cargo features (`psnr`, `ssimulacra2`), both enabled by default.
